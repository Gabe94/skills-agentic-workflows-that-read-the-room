## Recent GitHub updates (August 2026)

- **Copilot code review effort levels are generally available.** Reviewers can now pick a review depth (quick vs. thorough) to balance speed and coverage on pull requests.
  Source: https://github.blog/changelog/2026-08-07-copilot-code-review-effort-levels-are-generally-available/
- **Copilot code review adds resolution reasons and expanded capabilities.** Authors can now record why a review comment was resolved, giving teams clearer audit trails on PR feedback.
  Source: https://github.blog/changelog/2026-08-27-copilot-code-review-resolution-reasons-and-expanded-capabilities/
- **Agent Plugins 1.0 launched for VS Code, Copilot CLI, and the Copilot app.** A shared plugin format lets developers extend Copilot's agent behavior consistently across surfaces.
  Source: https://github.blog/changelog/2026-08-12-agent-plugins-1-0-in-vs-code-copilot-cli-and-the-copilot-app/
- **The GitHub Copilot app added a Customize tab (GA).** Developers can now tailor Copilot app behavior and preferences directly from a dedicated settings tab.
  Source: https://github.blog/changelog/2026-08-25-github-copilot-app-customize-tab-is-generally-available/
- **Copilot agentic work can now be shared in Microsoft Teams and Slack.** New integrations let teams follow and collaborate on Copilot agent sessions from chat apps they already use.
  Source: https://github.blog/changelog/2026-08-21-shared-agentic-work-with-github-copilot-in-microsoft-teams/ and https://github.blog/changelog/2026-08-21-the-new-github-copilot-experience-in-slack/
- **How canvases make agentic workflows visible, steerable, and cost-efficient.** A practical look at using canvases to track and steer multi-step Copilot agent work instead of following a raw chat log.
  Source: https://github.blog/ai-and-ml/github-copilot/how-canvases-make-agentic-workflows-visible-steerable-and-cost-efficient/
- **Turn one giant AI-generated pull request into a reviewable stack.** Guidance on splitting large agent-generated diffs into a series of smaller, reviewable stacked PRs.
  Source: https://github.blog/engineering/turn-one-giant-ai-generated-pull-request-to-a-reviewable-stack/
